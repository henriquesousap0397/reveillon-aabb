# Réveillon AABB Balsas 50 anos

Hotsite oficial de **O Réveillon da Nossa História**, a festa da virada de 31/12/2026 na sede da AABB Balsas, que celebra os 50 anos do clube.

- `index.html`: o site inteiro (página única)
- `assets/`: imagens

## Publicação

Hospedado no **Cloudflare Pages**, projeto `reveillon`, branch `main`. Toda atualização enviada para a `main` vai para o ar sozinha.

Configuração do projeto no Cloudflare:

- Framework: None
- Comando de build: vazio
- Diretório de saída: `/`

Endereço: https://reveillon.pages.dev (confirmar o endereço real gerado pelo Cloudflare).
